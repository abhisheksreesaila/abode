# Lessons

- Stay wire-compatible with the official T3 mobile app: never change an existing contract field, default, or link format. Encode new meaning inside the existing shapes, or add optional fields that older parsers ignore.
- Run tests from inside the package (`cd apps/web && vp test run src/...`), not from the repo root, or stale copies under `.claude/worktrees/` get picked up.
- Health-check loops in ops scripts need curl timeouts (`--connect-timeout`, `--max-time`), or a rollback can hang forever.
- Host updates restart the server that agents run under, so `scripts/abode/host.sh update` re-launches itself via `systemd-run`. Never run the update inline from an agent turn.
- Never add numbered DB migrations in the fork: upstream's next number would collide, and the migrator silently skips ids at or below the latest one recorded. Fork schema changes go in an idempotent "ensure" step that runs after the numbered migrations.
- Don't delete upstream files the fork stops using (e.g. the inbox Sidebar.tsx). Leave them unused: deleting them causes a modify/delete conflict on every monthly upstream merge.
- Builders must only edit inside their own worktree. Before each merge, check that the main checkout's `git status` is clean; a builder once leaked an uncommitted edit into main.
- Upstream Orchestration V2 (protocol 2) refuses V1 peers in both directions. Before pulling upstream, check `ORCHESTRATION_PROTOCOL_VERSION` and the official mobile app's version. A protocol bump breaks the phone until abode follows.
- Engine edits made the first fork unmergeable (75 conflicts after 10 days). abode code lives in `abode/` folders, and upstream files only get small `abode:`-marked hooks that `scripts/abode/hook-report.sh` keeps under budget.
- Tests and typecheck don't catch the production build's license check. After adding a dependency, run `cd apps/web && vp build --outDir <scratch>` before calling the ticket done.
- The app opens on a new-thread draft, not a thread. Anything that needs "the current thread" must also work on a draft (the draft's own `threadId` keys its side panel); A-006 passed review but every Customizations button was disabled in the real app.
- Test against the user's real setup, not just fixtures: most of their skills are symlinks (`~/.claude/skills/x -> ~/.agents/skills/x`), which a symlink-strict path check rejected.
- Upstream catches some keys app-wide in the capture phase (`mod+s` stashes the composer prompt). A key an abode panel needs must be excluded in that handler, or the panel never sees it.
- Every effect that hands state to a DOM node must survive React's dev double-mount: reset any "already done" ref in the cleanup, or the second mount skips the work (A-011 avatars vanished in dev).
- A wake (a background subagent finishing, a delegated result) is a new run. Anything shown "per turn" must group the user's run with the wake runs after it (`workStartedAt`; skip runs that never started), or it flickers or blanks mid-batch (A-020 took three review rounds).
- A service provided inside `ws.ts`'s per-connection `layerWsRpc` is rebuilt for every WebSocket and its scope closes once the connection is wired, so anything it forks dies at once. A service that owns background work or shared state (A-029 voice: the model download, idle timers, the 1.4 GB model) is built once in the outer `Layer.unwrap` and handed in with `Layer.succeedContext`. Unit tests with their own long scope cannot catch this; check the real wiring.
- abode web code must compile under the React Compiler and pass `t3code/no-manual-memo`: no `useMemo`/`useCallback` (use `useStableCallback` only where a handler leaves a large component) and no `try/finally` in components or hooks (use `promise.finally(...)` or cleanup after the `await`). `apps/web/src/reactCompilerCoverage.test.ts` and `vp lint apps/web/src/abode` enforce it.
- Changing what `/` shows breaks anything scoped to "the current session" (Customizations went dead on the Control room). When a route stops having a thread or draft, give session-scoped UI a fallback (`scopeFallback.ts` borrows the latest session) and check the sidebar on that route.
